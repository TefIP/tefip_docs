# TefIP Docs

Site de documentação pública da API do TefIP, construído com [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Pré-requisitos

- Python 3.9+
- pip

---

## Instalação

```bash
pip install mkdocs-material
```

---

## Desenvolvimento local

```bash
mkdocs serve
# → http://127.0.0.1:8000
```

---

## Build

```bash
mkdocs build
# gera o site estático em site/
```

---

## Estrutura

```
mkdocs.yml
docs/
  index.md
  getting-started.md
  assets/
  api/
    ask.md  display.md  sale.md  print.md
    status.md  transaction.md  swagger.md
```
